# Распознавание жестов (CNN на PyTorch)

Небольшая свёрточная нейросеть, которая распознаёт 5 жестов руки по изображению с веб-камеры в реальном времени.

Проект изначально был собран в блочной среде **NNTrack**, затем архитектура и параметры обучения были перенесены на **Python + PyTorch** один в один.

**Классы:** `catch`, `down`, `release`, `stop`, `up`

## Архитектура

```
Вход 64×64×3
 └─ [Conv2D(32, 3×3, valid) → ReLU → BatchNorm → MaxPool(2×2)] × 3
     └─ Flatten → Dense(5) → Softmax
```

Размерности по слоям:

| Этап            | Форма        |
|-----------------|--------------|
| Вход            | 3 × 64 × 64  |
| После блока 1   | 32 × 31 × 31 |
| После блока 2   | 32 × 14 × 14 |
| После блока 3   | 32 × 6 × 6   |
| Flatten         | 1152         |
| Выход (Softmax) | 5            |

Всего обучаемых параметров: 25 349.

## Параметры обучения

Перенесены из отчёта NNTrack:

| Параметр               | NNTrack                          | В коде PyTorch                          |
|------------------------|----------------------------------|-----------------------------------------|
| Размер изображения     | 64×64                            | `IMG_SIZE = 64`                         |
| Размер партии          | 20                               | `BATCH_SIZE = 20`                       |
| Эпохи                  | 32                               | `EPOCHS = 32`                           |
| Оптимизатор            | Adam, lr = 0.001                 | `optim.Adam(lr=0.001)`                  |
| Функция потерь         | Categorical crossentropy         | `nn.CrossEntropyLoss()`                 |
| Разбиение train / val  | 80% / 20%                        | `VAL_SPLIT = 0.2`, seed = 42            |
| Аугментация            | rotation 0.05, zoom 0.1          | `RandomRotation(18°)`, масштаб 0.9–1.1  |
| Early stopping         | val_loss, min_delta 0.05, patience 2 | `ES_MIN_DELTA`, `ES_PATIENCE`       |

Поворот 0.05 в Keras-нотации — это доля полного оборота: 0.05 × 360° = 18°.

## Датасет

Датасет в репозиторий не входит (большой размер). Он состоит из 2500 изображений, по 500 на каждый класс, и должен лежать рядом со скриптами в таком виде:

```
dataset/
├── catch/
├── down/
├── release/
├── stop/
└── up/
```

Названия классов берутся из имён папок. `ImageFolder` сортирует их по алфавиту, поэтому порядок классов в `CLASS_NAMES` (в `camera_demo.py`) тоже должен быть алфавитным.

## Установка

```bash
git clone <адрес-репозитория>
cd <папка-репозитория>

python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/macOS:  source .venv/bin/activate

pip install -r requirements.txt
```

## Использование

**1. Проверка датасета на битые изображения**

```bash
python check_dataset.py
```

По умолчанию файлы только выводятся в консоль. Чтобы битые файлы удалялись автоматически, поставьте `AUTO_DELETE = True` в начале скрипта.

**2. Обучение**

```bash
python gesture_net.py
```

Скрипт печатает порядок классов и метрики каждой эпохи, а лучшие веса (по `val_loss`) сохраняет в `gesture_net_best.pt`. Чтобы только проверить размерности слоёв без обучения, раскомментируйте `check_architecture()` в конце файла.

**3. Демо с веб-камеры**

```bash
python camera_demo.py
```

Покажите жест в зелёном квадрате в центре кадра. Выход — клавиша `Q`.

В репозитории лежат готовые веса `gesture_net_best.pt`, так что демо запускается без обучения.

### Настройки демо (`camera_demo.py`)

| Переменная             | Что делает                                                          |
|------------------------|---------------------------------------------------------------------|
| `CLASS_NAMES`          | Список классов, должен совпадать с порядком, который напечатало обучение |
| `CONFIDENCE_THRESHOLD` | Порог уверенности (по умолчанию 0.6); ниже него выводится `unknown` |
| `ROI_SIZE`             | Размер квадрата захвата в пикселях (по умолчанию 300)               |
| `cv2.VideoCapture(0)`  | Номер камеры; если не открывается, попробуйте `1`                   |

Внутри демо вырезанная область переводится из BGR в RGB, масштабируется до 64×64 и подаётся в сеть без аугментации, как на валидации.
